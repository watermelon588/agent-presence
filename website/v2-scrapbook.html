One global package. Needs Node 18 or newer.

        npm i -g agent-presence
      

      

        
        
        then,
        
Hook it up.

        
Adds hooks to Claude Code and Codex. Your old settings are backed up.

        agent-presence init

Watch.

        
Stickers float above every window. Clicks pass straight through.

        agent-presence overlay
