Guide

See which AI agent is editing which file, in VS Code.

When agents work in your repo, the Explorer gives no hint of where. The Agent Peeps extension adds a colored badge to every file an agent is reading or writing, and a panel listing what each agent touched.

What it shows

  • Explorer badges: each file an agent works on gets the agent's initial in its color: 🅒 Claude Code, 🅧 Codex, 🅟 Copilot, 🅐 Antigravity. Subagents show their type's initial, for example 🅔 for an Explore helper.
  • Folders light up around active files, so you spot where agents are working in a large tree.
  • An Agents view in the Explorer sidebar: every running agent with its sticker, its subagents and the files it touched. Click a file to open it.
  • A badge fades a while after the agent moves on (90 seconds by default, agentPresence.recentSeconds).

Set it up

The extension reads the event log the Agent Peeps hooks write, so add the hooks first:

$ npx agentpeeps init

Then install the extension. Until the Marketplace listing is live, install the .vsix from the repo's vscode folder:

$ code --install-extension agent-presence-vscode-0.1.0.vsix

Use cursor, windsurf or antigravity in place of code for those editors: they are built on VS Code and run the same extension.

Which agents it sees

It shows whatever the hooks report: Claude Code, Codex, GitHub Copilot (agent mode and CLI) and Antigravity, wherever they run, including in a terminal inside Cursor. The built-in agents of Cursor and Windsurf don't report through these hooks yet.

Customize the badges

// settings.json
"agentPresence.badges": {
  "claude": "C",
  "codex": "X",
  "Explore": "🔍"
}

Keys are agent names, subagent for every helper, or a subagent type. Colors are theme colors (agentPresence.claude, agentPresence.codex...) you can override in workbench.colorCustomizations.

Try it in one command

Agent Peeps is free and open source (MIT). It only reads hook events on your machine: no account, no server, no network.

$ npx agentpeeps init
$ npx agentpeeps overlay
