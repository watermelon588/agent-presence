Guide

Running several coding agents at once, without losing track.

Parallel agents are the fastest way to get work done, until you lose track of them. A practical setup for running Claude Code, Codex and Copilot side by side.

The problem with parallel agents

One agent is easy to watch. With three you get a new kind of overhead: you check each terminal in turn to see whether it is still working, finished, or stuck on a question. Two things go wrong:

  • Idle time. An agent waiting on a permission prompt does nothing until you notice.
  • Collisions. Two agents edit the same file, or one runs the tests while another is halfway through a refactor.

1. Give each agent its own lane

Split work so agents don't share files: one on the API, one on the UI, one writing tests. If your agents support it, run each one in its own git worktree so their changes stay apart until you merge them.

$ git worktree add ../app-api -b api-work
$ git worktree add ../app-ui -b ui-work

2. Make every agent's state visible

You want to know, without switching windows: which agent is working, on which file, and which one needs you. All four major coding agents can report this through hooks. Agent Peeps turns those events into one sticker per session on top of your screen:

  • an icon for the state: thinking, reading, writing, running, browsing, delegating, done or needs you,
  • a smaller sticker per subagent, joined to its parent,
  • on hover, the file it's on and the files it touched.
$ npx agentpeeps init
$ npx agentpeeps overlay

Give each agent its own look so you can tell them apart at a glance:

$ agentpeeps set claude capybaras
$ agentpeeps set codex cats
$ agentpeeps set helpers fruit-cats

3. Catch file collisions

The Agent Peeps VS Code extension puts a badge in the Explorer on each file an agent is touching, in that agent's color. When two badges land in the same folder, you see it before the merge conflict.

4. Check in on a schedule, not constantly

With states visible, stop polling terminals. Answer the agent that needs you, glance at the stickers when one finishes, and spend the time in between reviewing diffs. In the terminal, agentpeeps watch gives the same overview in a few lines.

Try it in one command

Agent Peeps is free and open source (MIT). It only reads hook events on your machine: no account, no server, no network.

$ npx agentpeeps init
$ npx agentpeeps overlay
